# Consignes de collaboration

## Périmètre des prompts collés

Le projet de ce dépôt est GeoFlow.

Avant d'exécuter un prompt collé par l'utilisateur, vérifier qu'il concerne le projet courant. Si ce prompt concerne un autre projet ou n'a aucun rapport avec le projet courant, signaler explicitement le décalage et s'arrêter. Ne lancer aucune commande, inspection, modification ni autre opération liée à ce prompt. Attendre une instruction explicite de l'utilisateur avant de changer de projet ou de poursuivre.
